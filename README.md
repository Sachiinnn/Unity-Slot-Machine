# Unity Slot Machine

A slot machine game developed in Unity featuring animated reels, randomized symbols, adjustable bets, a coin balance, and payouts for matching symbols.

## Play the Game
https://sachiinnn.github.io/Unity-Slot-Machine/Build/WebGL/

The game is hosted on GitHub Pages and can be played directly in a web browser.

## Features
- Animated slot reels
- Randomized symbol outcomes
- Matching-symbol win detection
- Adjustable bet amount
- Coin balance and payout system

## Controls
- SPIN: Spin the reels.
- Increase Bet: Increase the bet amount.
- Decrease Bet: Decrease the bet amount.

## How to Run Locally
1. Open the project in Unity.
2. Open the main scene.
3. Press Play to run the game.

## Project Structure
- Assets/Scripts/ - Game logic and scripts.
- Assets/Arts/ - Pngs and UI Icons.
- Build/WebGL/ - WebGL build hosted on GitHub Pages.
